# Fortune Waterfront

Dedicated marketing site for **Fortune Waterfront** — 3 BHK gated community apartments in Kukatpally by Sri Sreenivasa Infra.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Content and imagery reference the official project page at [srisreenivasa.com/portfolio/fortune-waterfront](https://srisreenivasa.com/portfolio/fortune-waterfront/).
